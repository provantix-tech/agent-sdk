Provantix evidence export
=========================

What this is
  A copy of recorded agent actions with the hashes, chain links and daily roots that let you check they were not changed after they were recorded.
  It holds 0 records chosen by name (cost statement 2026-10, version 1), not every record this organization had stored: 0 records, with no records. It says nothing about activity that was not delivered to Provantix, and nothing about records outside this export.

Two things a passing check never means
  1. A valid signature shows who signed this. It does not show that what is signed is true.
  2. Integrity is not completeness. Nothing in here was altered since it was recorded, but that does not show that every action was captured.

How to check it yourself
  Use the verification kit (Node and Python verifiers, no account needed): https://docs.provantix.tech/getting-started/verification-kit
  The format is described in FORMAT.md in the kit. Get Provantix's published keys yourself, never from this folder.
